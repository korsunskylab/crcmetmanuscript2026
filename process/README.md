# Processing and Analysis

This directory is reserved for workflows that prepare data for plotting. No runnable scripts are available yet.

- `scrna/`: single-cell RNA analysis.
- `tcr/`: T-cell receptor analysis.
- `xenium/`: spatial transcriptomics analysis.

See the [data access guide](../docs/data_access.md) for available inputs and setup instructions.

Use `data/` for inputs and `results/` for generated outputs, relative to the repository root.
