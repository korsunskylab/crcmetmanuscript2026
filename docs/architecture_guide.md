# Repository Structure

## Current directories

All paths below are relative to the repository root.

| Directory | Current contents |
| --- | --- |
| `additional_analyses/` | All original notebooks, scripts, and the original README, preserved unchanged. |
| `plot/` | `scrna_global_umap.ipynb` and a README. |
| `data/` | Local input data; excluded from Git and absent from a fresh clone. |
| `docs/` | User guides, data inventories, notebook input mappings, and provenance records. |
| `process/` | A README and placeholders under `scrna/`, `tcr/`, and `xenium/`; no processing scripts. |
| `R/`, `envs/`, `config/` | Placeholder directories only. |
| `results/` | A placeholder only; no generated results. |
