# Figure Generation

Use the notebooks in this directory to generate manuscript figures. Notebooks are named by analysis topic.

Before running a notebook:

1. Find its figure panels and required input files in the [figure map](../docs/figure_map.tsv).
2. Check the [data manifest](../docs/data_manifest.tsv) for data versions, download links, and checksums.
3. Follow the [data access guide](../docs/data_access.md) to download, place, and verify the required files.

Place input files under `data/` and save generated figures and tables under `results/`. Both paths are relative to the repository root.

The Zenodo data release is pending; see the data access guide for current availability.
